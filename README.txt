REWIND REFERENCE EFFECTS LAB — VERSION 2

This is a stand-alone effects editor with stronger reference-inspired visual recipes.

Included looks: Glass of Imagination, Dream Dance, Golden Embrace, Firefly Spirits, Neon Bond, Cosmic Lovers, Prismatic Samurai, Rainbow Dream Garden, Analog Motion 90s, and Starlight Armor.

The app includes highlight-masked glow/bloom, colored halation, palette remapping, saturation/contrast controls, true RGB channel separation, directional motion trails, zoom blur, double exposure, prism flares, corner light leaks, atmospheric haze, blurred light rays, stable star particles, neon edge glow, grain, dust, scratches and film frames. Custom presets can be saved locally.

PWA install: upload index.html, manifest.json, sw.js, and icon.svg together to an HTTPS static host (Vercel, Netlify, GitHub Pages). Then open the site in Chrome and choose Install app / Add to Home screen. A standalone file:// HTML cannot register a service worker by itself.

Honest limitation: these are image effects, not a generative AI model. They can recreate the colors, glow, trails, particles and film atmosphere of the references. They cannot reliably invent new subjects/objects (for example a sparkling-armored person) or isolate people perfectly without segmentation/masking.
